# LwX.Web.Testing.Viewer

Optional visual dashboard for `LwX.Web.Testing` reports and Playwright artifacts.

This project is intentionally separate from the core test engine. It can read:

- `run-summary.json` generated by `LwX.Web.Testing`
- screenshots
- videos
- Playwright trace ZIPs
- HAR files
- logs
- loose artifact folders when no structured report exists yet

## Run from source

```powershell
dotnet run --project ./src/LwX.Web.Testing.Viewer -- --results ./test-results-example
```

Or with your real test output:

```powershell
dotnet run --project ./src/LwX.Web.Testing.Viewer -- --results C:/path/to/test-results
```

## Pack as a dotnet tool

```powershell
./build/pack.ps1
```

Later, after publishing:

```powershell
dotnet tool install --global LwX.Web.Testing.Viewer --prerelease
lwx-test-viewer --results ./test-results
```

## Compatibility

The viewer includes compatible report contracts for the JSON generated by `LwX.Web.Testing`. It does not reference the core package so it can stay optional and lightweight.
